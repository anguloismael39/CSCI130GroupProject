Rules

Objective

Find the hidden five-letter word. You have six guesses.

Making a guess

  • Type letters with your keyboard or the on-screen keyboard. Use Backspace to delete and Enter to submit.
  • A guess must have exactly five letters and must be a word from the game's word list. Invalid guesses are rejected with a message and do not use up a try.

Color and symbol meanings

Every letter gets a color and a symbol, so the meaning never depends on color alone.

  • A Green with ✓ – the letter is in the word and in the correct position.
  • B Amber with ↔ – the letter is in the word but in a different position.
  • C Gray with ✕ – the letter is not in the word (or all its occurrences are already accounted for).

Repeated letters

Letters are matched using counts. Exact matches are marked first. Then each remaining letter is marked as misplaced only while the target still has an unused copy of it. A letter is never credited more times than it appears in the hidden word. For example, if the word has one E and you guess two, only one E can be green or amber; the other is gray.

Scoring

A win on the first guess is worth 1024 points. The value is halved for each additional guess (score = 1024 / 2n−1). An unsolved game earns 0 points.

End of the game

The game ends immediately when you find the word or after your sixth incorrect guess. The word, your result, points earned and elapsed time are then shown. The timer starts when the board is ready and stops when the game ends.

Accounts and the leaderboard

Guests can play freely, but only logged-in players have their results saved. Abandoned games (starting a new game before finishing) earn no points and add no time. The leaderboard shows cumulative score, games played, total time played and completed games for every player.
